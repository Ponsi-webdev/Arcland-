# ARCLAND Investments Ltd website

Stage 2, part 1: Homepage and Properties page.

- `index.html` is a single self-contained file (styles, scripts, logo and photos are embedded). No build step is needed.
- Pages are switched with hash links (`#/`, `#/properties`). About, Contact and property detail pages are placeholders for now.

## Publish with GitHub Pages
1. Create a new repository on GitHub and upload the contents of this folder (`index.html`, `README.md`, `.nojekyll`).
2. Open Settings, then Pages.
3. Under "Build and deployment", choose "Deploy from a branch", select the `main` branch and the `/ (root)` folder, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.
