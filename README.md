# ARCLAND Investments Ltd website

Upgraded homepage (Why Choose ARCLAND, premium property cards, FAQ, closing call-to-action) and Properties page.

- `index.html` is a single self-contained file (styles, scripts, logo and photos are embedded). No build step is needed.
- Pages are switched with hash links (`#/`, `#/properties`). About, Contact and property detail pages are placeholders for now.

## Replace the old version on GitHub
1. In your repository, upload this `index.html` over the old one (add `.nojekyll` if it is missing).
2. Commit the change.
3. GitHub Pages updates within a minute or two; refresh without cache if you still see the old page.
