# ARCLAND Investments Ltd website

Premium rebuild: Homepage and Properties page.

- `index.html` is a single self-contained file (styles, scripts, logo and photos are embedded). No build step is needed.
- Pages are switched with hash links (`#/`, `#/properties`). About, Contact and property detail pages are placeholders for now.

## Publish with GitHub Pages
1. In your existing repository, replace the old `index.html` with this one (also add `.nojekyll` if it is missing).
2. Commit the change.
3. In Settings, then Pages, confirm the site deploys from the `main` branch, `/ (root)` folder.
4. After a minute the updated site is live.
